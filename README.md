  <h2>Descrição do Projeto</h2>
    <p>O site "Guia de Viagens" foi desenvolvido utilizando as tecnologias HTML e CSS e apresenta os seguintes recursos:</p>
    <ul>
        <li><strong>Design Responsivo:</strong> A interface do site é adaptável a diferentes tamanhos de tela, garantindo uma experiência de navegação fluida tanto em dispositivos móveis quanto em desktops.</li>
        <li><strong>Exploração de Destinos:</strong> Uma seção dedicada aos melhores destinos do mundo, com imagens e links para páginas detalhadas de cada local. *somente a pagina do local Grand Cayman está disponivel para ser acessada no momento.</li>
        <li><strong>Novidades em Vídeo:</strong> Integração com um vídeo de novidades sobre viagens, que oferece uma visão atualizada das tendências e dos destinos mais populares.</li>
        <li><strong>Links Úteis:</strong> Acesso direto ao GitHub da desenvolvedora Laura Leite, onde o código-fonte do projeto pode ser explorado.</li>
    </ul>

  <h2>Funcionalidades do Projeto</h2>
    <p>O site inclui as seguintes funcionalidades:</p>
    <ul>
        <li>Menu de navegação com atalhos para diferentes seções do site, facilitando a navegação do usuário.</li>
        <li>Imagens de alta qualidade para ilustrar os destinos recomendados, com links para páginas detalhadas (quando disponíveis).</li>
        <li>Integração com vídeo via iframe, permitindo que os visitantes assistam a novidades sobre viagens diretamente na página.</li>
    </ul>
